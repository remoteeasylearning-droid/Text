# Лабораторія читання (НУШ)

Вебзастосунок для вчителів початкової школи для швидкого створення та друку дидактичних завдань з читання на основі будь-якого тексту за методиками НУШ.

---

## 🚀 Де працює застосунок?

### 1. Повнофункціональна версія (з підтримкою Gemini AI)
Застосунок є **Full-Stack (Node.js + Express + React + Gemini API)**:
- **Робоче посилання в AI Studio**: використовуйте опубліковану адресу застосунку на сервері (Google Cloud Run), де працює серверний бекенд `server.ts` та підключено Gemini API.

---

### 2. Розгортання на GitHub Pages (`https://remoteeasylearning-droid.github.io/Text/`)

#### Чому раніше виникала помилка 404 (`Failed to load resource: 404`)?
1. **GitHub Pages за замовчуванням є виключно статичним хостингом** і роздавав вихідний файл `index.html` з гілки `main`, який посилався на `/src/main.tsx`. Браузер не вміє читати сирий TypeScript (`.tsx`) напряму і шукав його за кореневою адресою домену, отримуючи 404.
2. Тепер налаштовано **відносний базовий шлях (`base: './'`)** у `vite.config.ts`, що дозволяє коректно завантажувати зібрані файли з будь-якого підкаталогу (наприклад, `/Text/`).
3. Додано готовий файл робочого процесу **`.github/workflows/deploy.yml`**.

#### Як увімкнути автоматичний білд для GitHub Pages:
1. Перейдіть у репозиторій на GitHub: `https://github.com/remoteeasylearning-droid/Text`
2. Відкрийте вкладку **Settings** -> **Pages**.
3. У розділі **Build and deployment** -> **Source** оберіть:
   👉 **GitHub Actions** (замість «Deploy from a branch»).
4. GitHub автоматично запустить робочий процес з `.github/workflows/deploy.yml`, збере проєкт за допомогою Vite (`npm run build`) і розгорне скомпільовану теку `dist` без жодних помилок 404.

*Примітка щодо GitHub Pages*: оскільки на GitHub Pages немає сервера Node.js, у разі відсутності бекенду застосунок автоматично активує **автономний методичний генератор**, який генерує завдання за методиками НУШ безпосередньо в браузері.

## 🛠 Локальний запуск

```bash
# Встановлення залежностей
npm install

# Запуск dev-сервера (Express + Vite)
npm run dev

# Збірка для продакшну
npm run build

# Запуск зібраного сервера
npm run start
```
